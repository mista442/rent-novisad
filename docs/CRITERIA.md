# Критерии поиска (из config.yaml)

| Параметр | Значение |
|---|---|
| Город | Novi Sad |
| Цена | 0–450 € в месяц (курс 117 RSD/€) |
| Комнат | 1–2 (1 = garsonjera) |
| Площадь | от 30 м² |
| Желаемые районы | Centar, Stari grad, Grbavica, Liman, Podbara, Detelinara |
| Исключить районы | Futog, Veternik, Petrovaradin, Kać, Begeč |
| Нужно (иначе пометка «уточнить») | internet, stove, fridge |
| Приятно иметь | washing_machine, air_conditioning, balcony, elevator, central_heating |
| Стоп-факторы (отсев) | agency_fee, no_registration, students_only, short_term_only |
| Свежесть | не старше 14 дней |

Объявление из чёрного списка `t.me/I_Black_list_Chat` отбрасывается всегда.
Если в объявлении нет цены/комнат/площади — оно **не** отсеивается, а получает пометку для уточнения.
